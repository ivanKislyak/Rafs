{% translate "Community guidelines" %}

{% blocktranslate trimmed %} RAFS brings together people who enjoy films, series, anime and animation. We value honest ratings, open discussion and respect for people, even when our tastes differ. {% endblocktranslate %}

{% translate "About the community and these rules" %}

{% blocktranslate trimmed %} These rules apply to reviews, replies, public profiles and other user publications on RAFS. They help us discuss what we watch freely while treating one another with respect. {% endblocktranslate %}

{% translate "Criticism and conversation" %}

{% blocktranslate trimmed %} Profanity, harsh reviews and unpopular opinions are allowed. Giving a film a low rating or disagreeing with the majority is not a violation in itself. Criticise the work and the arguments, rather than attacking the person behind an opinion. {% endblocktranslate %}

{% blocktranslate trimmed %} Threats, targeted harassment and degrading attacks based on origin, nationality, religion, gender or other personal characteristics are prohibited. {% endblocktranslate %}

{% translate "Spoilers" %}

{% blocktranslate trimmed %} If your review reveals important plot details, use the spoiler checkbox before publishing it. Replies do not have this checkbox: clearly warn readers about spoilers at the start of your reply, before revealing any plot details. {% endblocktranslate %}

{% translate "Spam and manipulation" %}

{% blocktranslate trimmed %} Mass posting of repeated content, intrusive advertising, phishing and malicious links are prohibited. Do not use additional accounts or automation to artificially increase reactions, ratings or Frames. Useful links and relevant mentions of other resources are welcome. {% endblocktranslate %}

{% translate "Personal data and prohibited content" %}

{% blocktranslate trimmed %} Do not publish another person’s non-public personal data without their consent. Pornographic avatars and public materials, calls for violence, extremist propaganda and illegal content are prohibited. {% endblocktranslate %}

{% blocktranslate trimmed %} Discussing or critically analysing these subjects as they appear in films is not, in itself, propaganda. Keep the distinction between examining a theme and promoting violence or extremism. {% endblocktranslate %}

{% translate "Moderation" %}

{% blocktranslate trimmed %} The RAFS founder defines the rules and appoints moderators. Moderators act within their assigned authority and the published rules. {% endblocktranslate %}

{% blocktranslate trimmed %} Possible measures include a request to edit a publication, hiding or removing content, a warning, a temporary restriction or an account ban. The measure depends on the severity, context and repetition of the violation. Warnings do not have to precede every restriction or ban. {% endblocktranslate %}

{% translate "Review of moderation decisions" %}

{% blocktranslate trimmed %} You may contact the administration to request a review of a moderation decision. Explain what happened and provide context that could affect the decision. Where possible, a different moderator will review your request. {% endblocktranslate %}

{% translate "Changes to the rules" %}

{% blocktranslate trimmed %} The current version of the community guidelines is available on this page. {% endblocktranslate %}
